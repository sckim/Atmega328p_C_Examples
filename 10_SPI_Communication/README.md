# 10. SPI Communication

## 🎯 학습 목표
*   SPI 마스터를 레지스터 수준에서 설정하고 MOSI/MISO/SCK/SS 네 신호의 역할을 이해한다.
*   클록 극성(CPOL)과 위상(CPHA)으로 정해지는 네 가지 모드를 구분한다.
*   하드웨어 SPI와 소프트웨어 SPI(비트뱅잉)를 비교한다.

## 🛠 주요 부품
*   MAX7219 도트 매트릭스 / 7-세그먼트 드라이버, MCP41xx 디지털 가변저항, 74LS595

## 💻 주요 레지스터
| 레지스터 | 역할 |
|---|---|
| `SPCR` | `SPE` 허용, `MSTR` 마스터, `CPOL`/`CPHA` 모드, `SPR1:0` 클록 분주 |
| `SPSR` | `SPIF` 전송 완료 플래그, `SPI2X` 배속 |
| `SPDR` | 송수신 데이터. 쓰면 전송이 시작되고, 동시에 수신값이 들어온다 |


## 📌 참고
*   마스터로 쓸 때도 `SS`(PB2) 핀은 출력으로 설정해야 한다. 입력으로 두면 Low가 들어올 때 슬레이브 모드로 전환되어 버린다.
*   SPI는 전이중 방식이다. 읽기만 필요해도 더미 바이트를 써 넣어야 클록이 발생한다.
